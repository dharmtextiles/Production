Tap a box (machine / date), press Voice entry, then speak numbers.
Voice: say a number → it is filled and the next date opens. Say “skip” / “next” to leave a day blank, “back” to go up, “stop” to finish. You can also say several numbers together (24 25 26). Leave blank for a machine that did not run. Press Enter to move down. Average = machine total ÷ days it ran. Count = machines running that day. Efficiency = production ÷ 100% target (see Report tab for settings).
