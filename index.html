Continuous backup to a file on this computer

Automatic backup to a file needs Chrome or Edge on a computer. On this browser use the snapshots above, Google Drive and Export.

Google Drive backup (continuous)

Backups go to a hidden app folder in your Google Drive (not shown in the Drive file list). One latest copy plus one copy per day for the last 14 days. Google login lasts 1 hour; tap anywhere on the page once to renew it silently.
One-time setup — how to get the Client ID
  1. Open console.cloud.google.com → create a project (any name).
  2. APIs & Services → Library → search “Google Drive API” → Enable.
  3. OAuth consent screen (Google Auth Platform) → User type External → fill app name and your email → add your Gmail under Test users → under Scopes add .../auth/drive.appdata.
  4. Credentials → Create credentials → OAuth client ID → Application type Web application → under Authorized JavaScript origins add your site address, e.g. https://yourname.github.io (no path, no trailing slash).
  5. Copy the Client ID, paste it above, press Connect Google Drive and allow access. Google may warn “app not verified” — choose Advanced → Continue (it is your own app).
